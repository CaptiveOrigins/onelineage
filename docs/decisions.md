# Decisions

Dated decisions for this repo, newest last. The fuller design plan is kept privately by the owner. Decisions that matter here are copied in without private details.

- 2026-11-10: created from the ops starter kit, area `genealogy`.
- 2026-11-09 (owner): owned by Captive Origins, part of the OneOrigin family, under PolyForm Noncommercial. TypeScript.
- 2026-11-09 (owner): **public from the start.** The owner's words: "it's fine if it's public", then "It can be public? I mentioned that". The leak check runs in CI from the first commit, and a first-public-push audit comes before the first push.
- 2026-11-09 (owner): free, Mac only, no servers. The user chooses where the library lives. Two backups by default, with a deliberate way to go down to one or none.
- 2026-11-10 (owner): implement everything technically possible without breaking any service's terms. Enforced by the terms register (ADR 0004).
- 2026-11-09 (owner): our own exporter is built and tested against a mock site. It stays off for Ancestry until there's a partnership.
- 2026-11-09 (owner): no law-enforcement use from day one. Sanctioned, verifiable investigative genetic genealogy labs and wildlife agencies are allowed. See `USE-POLICY.md`. The exact line is still open.
- 2026-11-09 (owner): raw DNA uploads to GEDmatch only, done by the tester themselves. The app checks the law-enforcement setting.
- 2026-11-09 (owner): a GitHub connector keeps the history of a user's research only. It doesn't count as a backup.
- 2026-11-10: OneLineage reads published genetic maps in PLINK `.map` format, but doesn't bundle one yet. The usual GRCh37 map, distributed with Beagle and derived from HapMap, has no license stated on its download page. HapMap dropped its click-wrap license in 2004, but whether that covers derived map files isn't confirmed. Until it is, comparisons use the approximate 1 cM per Mb rule and say so. Bundling or downloading a map waits on the owner (task K320, owner item N124).
- 2026-11-10 (owner): the Chrome extension is the tool the Mac app uses to collect. It stores nothing, and talks to the app only through Chrome native messaging, never a localhost port. It's locked down: the host manifest's `allowed_origins` lists only our extension, and the host checks the caller's origin. The extension's `externally_connectable` has an empty `ids` list and no `matches`. A developer build ID is trusted only from the app's settings, as a recorded decision. The command list is fixed and short. Requests started in the extension need the owner's OK in the app: allow once, allow for this session (one kit, ending when Chrome closes or after 1 hour), or deny. Grants carry an expiry, only the minimum is handed over, the app logs what it handed over, and an active session grant shows in the app with "End now". Match details go in the side panel, never into the website's page. No automated page visits on any real site: build and test only against a local mock site with its own synthetic terms entry, at human pace (one page at a time, 30–60 s randomized pauses, a daily cap, and a stop at any challenge, sign-in page or error). A toolbar button toggles privacy in the app. See ADR 0009.
- 2026-11-10: privacy stand-ins on the testing services' own pages, through the extension, aren't built yet. They'd need a content script that writes into the page, which ADR 0009 avoids, and real services are refused by the terms register anyway. They're revisited only if a partnership allows reading those pages.
